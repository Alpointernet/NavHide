# NavHide

NavHide is a lightweight app for hiding the navigation bar on Samsung One UI devices using [Shizuku](https://github.com/rikkaapps/shizuku).

## Requirements

- Android 10 or later
- [Shizuku](https://github.com/rikkaapps/shizuku) installed and running

## Issues

- The navigation bar will reappear after a device restart
